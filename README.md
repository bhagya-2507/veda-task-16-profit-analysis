# 📊 Simple Profit Analysis using Excel

## 📌 Project Overview

This project focuses on analyzing sales and profit data using Microsoft Excel. The objective is to calculate category-wise total sales, total profit, and average profit, and present the insights through a professional chart.

## 🎯 Objectives

* Calculate total sales for each category.
* Calculate total profit for each category.
* Calculate average profit.
* Create a profit comparison chart.
* Improve Excel data analysis and visualization skills.

## 🛠️ Tools Used

* Microsoft Excel
* Excel Formulas
* SUMIF
* AVERAGEIF
* Column Chart
* Data Formatting

## 📂 Dataset

The dataset contains sales and profit records categorized into:

* Furniture
* Office Supplies
* Technology

## 📊 Analysis Performed

1. Category-wise Total Sales
2. Category-wise Total Profit
3. Average Profit Analysis
4. Profit Comparison using Column Chart

## 📈 Key Features

* Organized raw data
* Category-wise profit summary
* Excel formulas for calculations
* Professional formatting
* Data visualization using charts

## 📁 Project Files

* `Task_16_Simple_Profit_Analysis.xlsx` – Excel analysis workbook

Through this project, I practiced Excel data analysis, formulas, data formatting, and chart creation.
